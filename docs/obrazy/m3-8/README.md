# Przykłady odbioru M3

Arkusz wyprawy terenowej zawiera trzy neutralne szablony. Pomiary używają wspólnego stylu wartości
w rombach i kreski szkicowej. Dziennik trasy ma cztery panele, kolor z danych, stopkę oraz listę z
ikonami i dalszą częścią opisu. Zapasy łączą tabelę z kapitalikami, fakturą i postrzępionym obrysem.
