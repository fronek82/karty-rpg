# Makiety UI2 („drukarnia riso”)

Źródła makiet z Claude Design zaakceptowane 26.11.2026. Opis i etapy: [`docs/plan-UI2.md`](../plan-UI2.md).

Pliki `.dc.html` to zwykły HTML (style w atrybutach `style`) z krótką logiką w klasie `Component`
(`renderVals()`). Bez środowiska Claude Design się nie uruchomią (brak `support.js`), ale są
wiążącym wzorem kolorów, odstępów, tekstów i zachowania.
